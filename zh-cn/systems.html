Cipher CLI

使用 Go 编写的本地文件加密工具。AES-256-GCM 验证密文，Argon2id 从密码派生密钥，而不保存密钥。

密码算法 认证式对称加密 AES-256-GCM
KDF 内存硬派生参数 64 MB Argon2id
源码仓库 源代码 github.com/iTheoKL/cipher-cli

ThreatLens

检查可疑链接并解释判断依据的浏览器扩展。客户端启发式分析区分安全、可疑和恶意网址。

判级机制 安全 / 可疑 / 恶意 结论 + 原因
防护场景 浏览器与邮箱中的链接 浏览器与邮箱
语言 实现语言 纯 JavaScript
源码仓库 源代码 github.com/iTheoKL/ThreatLens
