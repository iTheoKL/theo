SYS.01 // Cipher-CLI 加密库 开源

基于 Go 语言构建的高安全保证命令行加密工具。采用内存密集型 Argon2id 算法动态派生密钥（$t=3, m=64\,\text{MB}, p=4$），并使用 AES-256-GCM 进行认证加密，旨在确保严格的常数时间执行并消除时序侧信道泄漏。

密码算法 认证式对称加密 AES-256-GCM
KDF 内存硬派生参数 64 MB Argon2id
源码仓库 仓库访问 github.com/iTheoKL/cipher-cli

SYS.02 // ThreatLens 浏览器扩展 开源

基于纯 JavaScript 编写的客户端安全浏览器扩展，专为实时拦截网页浏览及网页邮箱（Webmail）中的网络钓鱼攻击而设计。ThreatLens 不仅输出模糊的风险分值，更将风险划分为明确的三态判定（安全、可疑、恶意），并逐项透明展示触发判级背后的具体结构特征与启发式因果分析。

判级机制 三态明确判级与因果溯源（安全 / 可疑 / 恶意） 结论 + 原因
防护场景 网页实时冲浪与邮箱内钓鱼链接拦截 浏览器与邮箱
技术原语 纯客户端实现栈 纯 JavaScript
源码仓库 仓库访问 github.com/iTheoKL/ThreatLens

SYS.03 // MedBridge 引擎 闭源专有

多药联合冲突排查引擎与临床图分析统一平台。具备动态图遍历机制、EasyOCR 模型预加载与全局同步的安全会话管理。

架构论文：阅读 MedBridge：必然收敛的系统架构

SYS.04 // Aether-L3 撮合核心 闭源专有

基于 C++23 的零内存分配限价订单簿撮合引擎。将深度数据组织在 64 字节对齐的连续 SIMD 数组中，利用 AVX-512 向量广播指令在 14.2 纳秒内完成价格扫描。

延迟边界 确定性最坏情况执行时间 ≤ 14.2 ns
内存模型 撮合热路径上的堆分配 0 字节
向量指令 SIMD 硬件加速 AVX-512 / VBROADCAST
