SYS.04 // Aether-L3 Matching Core Closed Source

A zero-allocation limit order matching engine written in C++23. Standard matching implementations allocate nodes on the heap during order insertion, causing memory fragmentation, jitter, and cache-line invalidation. Aether-L3 organizes resting depth into contiguous 64-byte aligned SIMD arrays scanned via AVX-512 vector broadcasts in under 14.2 nanoseconds.

BOUND Deterministic Worst-Case Execution ≤ 14.2 ns
MEMORY Heap Allocation on Match Hot-Path 0 Bytes
VECTOR Vectorized Instruction Set AVX-512 / VBROADCAST
AetherRingBuffer.cpp (Vectorized Price Scan)
inline uint32_t match_vectorized(const uint64_t* prices, uint64_t limit_price, uint32_t len) noexcept {
    const __m512i target = _mm512_set1_epi64(limit_price);
    for (uint32_t i = 0; i < len; i += 8) {
        const __m512i chunk = _mm512_load_si512(reinterpret_cast<const __m512i*>(&prices[i]));
        const __mmask8 mask = _mm512_cmpge_epu64_mask(chunk, target);
        if (mask != 0) return i + std::countr_zero(mask);
    }
    return len;
}
