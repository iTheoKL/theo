Primitives d'Ingénierie

Un registre de primitives cryptographiques à temps constant, d'extensions d'intelligence contre les menaces, de moteurs sans allocation et de systèmes de graphes résilients.

SYS.01 // Coffre Cipher-CLI Open Source

Outil de stockage cryptographique de haute assurance en Go. Dérivation de clé en mémoire stricte Argon2id ($t=3, m=64\,\text{Mo}, p=4$), authentifié avec AES-256-GCM. Conçu pour garantir une exécution en temps constant et éliminer les fuites par canaux auxiliaires.

CHIFFREMENT Chiffrement symétrique authentifié AES-256-GCM
KDF Paramètre de mémoire stricte 64 Mo Argon2id
SOURCE Accès au dépôt github.com/iTheoKL/cipher-cli

SYS.02 // Extension ThreatLens Open Source

Extension de navigateur de sécurité côté client écrite en pur JavaScript, conçue pour intercepter en temps réel les attaques de phishing sur le web et dans les clients webmail. Au lieu d'un score opaque, ThreatLens classe les cibles selon trois verdicts nets (Sûr, Suspect, Malveillant) et expose les raisons structurelles et heuristiques précises derrière chaque alerte.

VERDICT Classification tri-état & explication causale (Sûr / Suspect / Malveillant) Verdict + Cause
PÉRIMÈTRE Navigation Web & Interception dans les Webmails Web & Messagerie
STACK Primitives d'implémentation Pur JavaScript
SOURCE Accès au dépôt github.com/iTheoKL/ThreatLens

SYS.03 // Moteur MedBridge Closed Source

Moteur de détection de conflits polymédicamenteux et plateforme de graphes cliniques unifiée. Intègre une analyse de graphes dynamique, le préchargement EasyOCR et une sécurité de session synchronisée.

Essai d'Architecture : Lire MedBridge : Une Architecture de Convergence Inévitable

SYS.04 // Noyau d'Appariement Aether-L3 Closed Source

Moteur de carnet d'ordres sans allocation dynamique en C++23. Structure la profondeur en tableaux contigus alignés sur 64 octets, balayés par vectorisation AVX-512 en moins de 14.2 nanosecondes.

BORNE Exécution déterministe pire cas ≤ 14.2 ns
MÉMOIRE Allocation sur le chemin critique 0 Octet
VECTEURS Jeu d'instructions vectorisées AVX-512 / VBROADCAST
