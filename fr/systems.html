Travaux

Implémentations choisies. Les décisions qui les fondent.

Cipher CLI

Un outil en Go pour chiffrer les fichiers locaux. AES-256-GCM authentifie le texte chiffré ; Argon2id dérive la clé d’un mot de passe. La clé n’est jamais stockée.

CHIFFREMENT Chiffrement symétrique authentifié AES-256-GCM
KDF Dérivation de clé 64 Mo Argon2id
SOURCE Code source github.com/iTheoKL/cipher-cli

ThreatLens

Une extension qui examine les liens suspects et explique son verdict. Des heuristiques locales distinguent les URL sûres, suspectes et malveillantes.

VERDICT Sûr / Suspect / Malveillant Verdict + Cause
PÉRIMÈTRE Liens dans le navigateur et la messagerie Web & Messagerie
STACK Langage Pur JavaScript
SOURCE Code source github.com/iTheoKL/ThreatLens

MedBridge

Une plateforme de gestion des médicaments conçue lors d’un hackathon. Saisie des prescriptions, interactions et analyse des symptômes réunies dans un système.
